# Obs para GPUs: Use --gres=gpu:1  
# Com --gres=gpu:1 apenas é alocado 1 GPU. Sem ele, será pedido todas as GPUs,
# sendo que pode não haver nó algum com todas GPUs disponíveis. 
# Neste caso será reportado o reason QOSMinGRES:
#    JOBID NAME             ST     TIME TIME_LIMI NODE NODELIST(REASON)
# 11312658 bash             PD     0:00     20:00    1 (QOSMinGRES)

# Ao sair (exit) o job será terminado
